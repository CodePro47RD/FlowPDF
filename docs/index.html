Pruebas Reales de Rendimiento

¿Por qué ReportForge y no HTML a PDF?

Las soluciones que levantan Chrome headless consumen gigabytes de memoria y tardan segundos por página. ReportForge utiliza composición vectorial matemática directa.

Métrica / Capacidad Motores Chromium (Puppeteer / Playwright) WeasyPrint (Python CSS Paged Media) ReportForge 2.0 (Rust Core) 🚀
Tiempo de Generación (1 pág) 🔴 2,500 ms – 4,500 ms 🟡 850 ms – 1,800 ms 🟢 15 ms – 35 ms
Uso de Memoria RAM 🔴 350 MB – 650 MB por worker 🟡 120 MB – 220 MB 🟢 14 MB – 24 MB
Salto de Páginas en Tablas 🔴 Frecuentes cortes a mitad de fila 🟡 Lento en documentos de 100+ págs 🟢 Exacto (medición fila por fila)
Repetición de Cabeceras 🔴 Inconsistente en CSS 🟢 Soportado (theader) 🟢 Nativo (repeat_header: true)
Soporte Acentos Españoles 🟢 Compatible (HTML UTF-8) 🟢 Compatible 🟢 WinAnsi Hexadecimal ISO 32000-1
Modo de Ejecución Solo vía Node.js / CLI Solo vía Python 🟢 In-Process Nativo + Microservicio HTTP

C# Paquete NuGet ReportForge 2.0.0

Multi-targeting compilado para net8.0, net9.0 y net10.0. Embedea automáticamente reportforge_native.dll y libreportforge_native.so.

dotnet add package ReportForge
Descarga local: ReportForge.2.0.0.nupkg (1.6 MB) ↓
Ejemplo de Implementación C# 
using ReportForge.Fluent;
using ReportForge.Native;
using System.IO;

// 1. Declarar documento fluido con soporte Unicode y acentos
var doc = ReportDocument.Create(page => page.A4().Portrait().Margin(15))
    .Title("Facturación Electrónica en C#")
    .Header(h => h.Row(r => {
        r.RelativeItem(3, c => {
            c.Text("REPORTFORGE ENTERPRISE").H2().Bold().Color("#1E40AF");
            c.Text("Facturación con acentos: á é í ó ú ñ Ñ ¿ ¡ €").Caption().Color("#4B5563");
        });
        r.RelativeItem(1, c => c.QrCode("https://reportforge.io/verify/FAC-9901", 60));
    }))
    .Content(c => {
        c.Spacer(10);
        c.Table(t => {
            t.Column("Código", "sku", col => col.Width(70));
            t.Column("Descripción", "desc", col => col.Flex(3));
            t.Column("Cant.", "qty", col => col.Width(50).Center());
            t.Column("Total", "total", col => col.Width(90).Right());
            t.HeaderBackground("#1E40AF");
            t.Zebra();
            t.Rows(new[] {
                new Dictionary<string, object> { ["sku"] = "SRV-01", ["desc"] = "Licencia Anual C#", ["qty"] = 1, ["total"] = "€ 1,200.00" },
                new Dictionary<string, object> { ["sku"] = "SUP-02", ["desc"] = "Soporte Técnico 24/7", ["qty"] = 2, ["total"] = "€ 300.00" }
            });
        });
        c.Spacer(15);
        c.Row(r => {
            r.RelativeItem(1, col => col.BarCode("FAC9901", "code128", 160, 35));
            r.RelativeItem(1, col => col.Text("Total: € 1,500.00").H2().Bold().Color("#16A34A").Right());
        });
    });

// 2. Renderizado In-Process directo en Rust en ~35 ms!
byte[] pdfBytes = doc.RenderPdf();
File.WriteAllBytes("factura_csharp.pdf", pdfBytes);
Console.WriteLine($"✅ PDF generado ({pdfBytes.Length} bytes) en microsegundos!");

import { ReportDocument } from 'reportforge';
import * as fs from 'fs';

const doc = ReportDocument.create(page => page.a4().portrait().margin(15))
    .header(h => h.row(r => {
        r.relativeItem(3, col => col.column(c => {
            c.text('REPORTFORGE ENTERPRISE', t => t.h2().bold().color('#1E40AF'));
            c.text('Facturación con acentos: á é í ó ú ñ €', t => t.caption());
        }));
        r.relativeItem(1, col => col.qr('https://reportforge.io/verify/FAC-9901', 60));
    }))
    .content(c => {
        c.spacer(10);
        c.table(t => {
            t.column({ title: 'Código', field: 'sku', width: 70 });
            t.column({ title: 'Descripción', field: 'desc', flex: 3 });
            t.headerBackground('#1E40AF');
            t.zebra(true);
            t.data([
                { sku: 'TS-01', desc: 'Módulo TypeScript Enterprise' },
                { sku: 'TS-02', desc: 'Soporte y Consultoría Bun / Deno' }
            ]);
        });
        c.spacer(10);
        c.row(r => {
            r.relativeItem(1, col => col.barcode('FAC9901', 'code128', { width: 160, height: 35 }));
            r.relativeItem(1, col => col.text('Total: € 1,500.00', t => t.h2().bold().color('#16A34A')));
        });
    });

// Renderizado directo a PDF en memoria
const pdfBytes = doc.renderPdf();
fs.writeFileSync('factura_ts.pdf', Buffer.from(pdfBytes));
console.log(`✅ PDF generado exitosamente (${pdfBytes.length} bytes) en ~25ms!`);

Ejemplo de Implementación Python 
from reportforge import ReportDocument

doc = (
    ReportDocument()
    .title("Factura en Python")
    .page(lambda p: p.a4().portrait().margin(15))
    .header(lambda h: (
        h.row(lambda r: (
            r.column(lambda c: (
                c.text("REPORTFORGE ENTERPRISE", lambda t: t.h2().bold().color("#1E40AF")),
                c.text("Acentos españoles sin mojibake: á é í ó ú ñ Ñ ¿ ¡ €", lambda t: t.caption().color("#4B5563"))
            ), flex=3),
            r.column(lambda c: (
                c.qr_code("https://reportforge.io/verify/FAC-PY", size=60),
            ), flex=1)
        ))
    ))
    .content(lambda c: (
        c.spacer(10),
        c.table(lambda t: (
            t.column("Código", "sku", lambda col: col.width(70)),
            t.column("Descripción", "desc", lambda col: col.flex(3)),
            t.column("Total", "total", lambda col: col.width(90).right()),
            t.header_background("#1E40AF"),
            t.zebra(True),
            t.data([
                {"sku": "PY-01", "desc": "Licencia Enterprise Python", "total": "€ 1,200.00"},
                {"sku": "SUP-02", "desc": "Soporte Técnico Dedicado", "total": "€ 300.00"}
            ])
        )),
        c.spacer(15),
        c.row(lambda r: (
            r.column(lambda col: col.barcode("FACPY2026", barcode_type="code128", width=160, height=35), flex=1),
            r.column(lambda col: col.text("Total: € 1,500.00", lambda t: t.h2().bold().color("#16A34A").right()), flex=1)
        ))
    ))
)

# Renderizado directo in-process en ~30ms
pdf_bytes = doc.render_pdf()
with open("factura_python.pdf", "wb") as f:
    f.write(pdf_bytes)

print(f"✅ PDF generado exitosamente ({len(pdf_bytes)} bytes)!")

PHP Composer reportforge/reportforge

Estándar PSR-4 con soporte nativo de PHP FFI (\FFI::cdef) para renderizado en microsegundos y cliente cURL de respaldo.

composer require reportforge/reportforge
Ejemplo de Implementación PHP 8+ 
<?php
require_once 'vendor/autoload.php';

use ReportForge\ReportDocument;

$doc = ReportDocument::create(fn($p) => $p->a4()->portrait()->margin(15))
    ->content(fn($c) => (
        $c->text("Facturación Electrónica en PHP", fn($t) => $t->h1()->bold()->color("#1E40AF")),
        $c->text("Acentos españoles sin mojibake: á é í ó ú ñ €", fn($t) => $t->caption()),
        $c->spacer(10),
        $c->table(fn($t) => (
            $t->column("Código", "sku", fn($col) => $col->width(70)),
            $t->column("Descripción", "desc", fn($col) => $col->flex(3)),
            $t->headerBackground("#1E40AF"),
            $t->zebra(true),
            $t->data([
                ["sku" => "PHP-01", "desc" => "Módulo PHP 8+ FFI Enterprise"]
            ])
        )),
        $c->spacer(10),
        $c->qrCode("https://reportforge.io/verify/FAC-PHP", size: 60),
        $c->spacer(10),
        $c->barcode("FACPHP2026", barcodeType: "code128", width: 160, height: 35)
    ));

// Renderizado directo nativo con PHP FFI
$pdfBytes = $doc->renderPdf();
file_put_contents("factura_php.pdf", $pdfBytes);
echo "✅ PDF generado exitosamente (" . strlen($pdfBytes) . " bytes)!\n";

JAR auto-contenido que extrae dinámicamente los binarios de Rust Core vía JNA. Cero dependencias JSON externas.

dev.reportforge:reportforge:2.0.0
Descarga JAR: reportforge-2.0.0.jar (1.5 MB) ↓
Ejemplo de Implementación Java 11+ 
import dev.reportforge.ReportDocument;
import java.io.FileOutputStream;
import java.util.List;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        ReportDocument doc = ReportDocument.create(p -> p.a4().portrait().margin(15))
            .title("Factura en Java")
            .content(c -> {
                c.text("Facturación Electrónica en Java", t -> t.h1().bold().color("#1E40AF"));
                c.text("Soporte Unicode completo: á é í ó ú ñ €", t -> t.caption());
                c.spacer(10);
                c.table(t -> {
                    t.column("Código", "sku", col -> col.width(70));
                    t.column("Descripción", "desc", col -> col.flex(3));
                    t.headerBackground("#1E40AF");
                    t.zebra(true);
                    t.data(List.of(
                        Map.of("sku", "JV-01", "desc", "Licencia Enterprise Spring Boot")
                    ));
                });
                c.spacer(10);
                c.qrCode("https://reportforge.io/verify/FAC-JAVA", 60);
                c.spacer(10);
                c.barcode("FACJAVA2026", "code128", 160, 35, true);
            });

        // Renderizado nativo in-process
        byte[] pdfBytes = doc.renderPdf();
        try (FileOutputStream out = new FileOutputStream("factura_java.pdf")) {
            out.write(pdfBytes);
        }
        System.out.println("✅ PDF generado exitosamente (" + pdfBytes.length + " bytes)!");
    }
}
