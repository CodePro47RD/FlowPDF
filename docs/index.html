Gráficos Estadísticos y Fuentes TTF
Vectores Nativos en PostScript sin Imágenes PNG.

Olvídate de renderizar gráficos en canvas HTML o generar pesadas imágenes PNG. ReportForge dibuja primitivas matemáticas vectoriales (re, m, l, f, S) directamente en el stream del PDF, con soporte para temas Light y Dark y la capacidad de incrustar fuentes TrueType (.ttf) personalizadas.

📊

Gráficos de Barras, Líneas y Área

Genera gráficos de barras agrupadas o simples, líneas de tendencia continuas y áreas sombreadas. Incluye cuadrículas automáticas, ejes formateados con escalas inteligentes (k/M) y leyendas dinámicas.

🍩

Gráficos de Pastel y Dona

Cálculo trigonométrico de sectores con arcos Bézier vectoriales de alta precisión. Soporte para radio interior configurable (Donut) y desglose automático de porcentajes en la leyenda.

🔤

Fuentes Personalizadas (TTF / OTF)

Incrusta fuentes de Google Fonts (Inter, Roboto, Montserrat) o las tipografías de tu manual de marca. Extracción automática de métricas con ttf-parser y generación del /FontDescriptor y /FontFile2 en el PDF.

Novedad en ReportForge 2.0

Extracción de Texto y Parsing Estructurado
en Menos de 1 Milisegundo.

No sólo generes reportes: ahora puedes ingerir, auditar y parsear documentos PDF existentes directamente en memoria. ReportForge incluye un motor nativo en Rust que inspecciona el árbol de objetos PDF (diccionarios, MediaBox, streams de contenido) y extrae texto plano o metadatos estructurados en JSON sin recurrir a Chromium, Poppler o Java.

⚡

Velocidad Sub-Milisegundo

Procesa miles de facturas o contratos por segundo. La extracción ocurre in-process en C-ABI con cero copias innecesarias de memoria, ideal para microservicios de alto tráfico y pipelines RAG de IA.

📄

Desglose por Páginas y Dimensiones

Obtén el texto individual de cada página, su número correlativo y sus dimensiones físicas exactas (ancho y alto en puntos tipográficos), preservando la estructura del documento.

🏷️

Metadatos Estructurados (JSON)

Inspecciona automáticamente el diccionario /Info del PDF: Título, Autor, Creador, Software Productor, y fechas de creación y modificación en formato JSON limpio.

Pruebas Reales de Rendimiento

¿Por qué ReportForge y no HTML a PDF?

Las soluciones que levantan Chrome headless consumen gigabytes de memoria y tardan segundos por página. ReportForge utiliza composición vectorial matemática directa.

Métrica / Capacidad Motores Chromium (Puppeteer / Playwright) WeasyPrint (Python CSS Paged Media) ReportForge 2.0 (Rust Core) 🚀
Tiempo de Generación (1 pág) 🔴 2,500 ms – 4,500 ms 🟡 850 ms – 1,800 ms 🟢 15 ms – 35 ms
Uso de Memoria RAM 🔴 350 MB – 650 MB por worker 🟡 120 MB – 220 MB 🟢 14 MB – 24 MB
Salto de Páginas en Tablas 🔴 Frecuentes cortes a mitad de fila 🟡 Lento en documentos de 100+ págs 🟢 Exacto (medición fila por fila)
Repetición de Cabeceras 🔴 Inconsistente en CSS 🟢 Soportado (theader) 🟢 Nativo (repeat_header: true)
Soporte Acentos Españoles 🟢 Compatible (HTML UTF-8) 🟢 Compatible 🟢 WinAnsi Hexadecimal ISO 32000-1
Modo de Ejecución Solo vía Node.js / CLI Solo vía Python 🟢 In-Process Nativo + Microservicio HTTP
Extracción de Texto y Metadatos 🔴 No nativo (requiere librerías pesadas / PDF.js) 🔴 No soportado (solo generación HTML a PDF) 🟢 Nativo in-process (< 1 ms, JSON estructurado)

Ejemplo de Implementación C# 
using ReportForge.Fluent;
using ReportForge.Native;
using System.IO;

// 1. Declarar documento fluido con soporte Unicode y acentos
var doc = ReportDocument.Create(page => page.A4().Portrait().Margin(15))
    .Title("Facturación Electrónica en C#")
    .Header(h => h.Row(r => {
        r.RelativeItem(3, c => {
            c.Text("REPORTFORGE ENTERPRISE").H2().Bold().Color("#1E40AF");
            c.Text("Facturación con acentos: á é í ó ú ñ Ñ ¿ ¡ €").Caption().Color("#4B5563");
        });
        r.RelativeItem(1, c => c.QrCode("https://reportforge.io/verify/FAC-9901", 60));
    }))
    .Content(c => {
        c.Spacer(10);
        c.Table(t => {
            t.Column("Código", "sku", col => col.Width(70));
            t.Column("Descripción", "desc", col => col.Flex(3));
            t.Column("Cant.", "qty", col => col.Width(50).Center());
            t.Column("Total", "total", col => col.Width(90).Right());
            t.HeaderBackground("#1E40AF");
            t.Zebra();
            t.Rows(new[] {
                new Dictionary<string, object> { ["sku"] = "SRV-01", ["desc"] = "Licencia Anual C#", ["qty"] = 1, ["total"] = "€ 1,200.00" },
                new Dictionary<string, object> { ["sku"] = "SUP-02", ["desc"] = "Soporte Técnico 24/7", ["qty"] = 2, ["total"] = "€ 300.00" }
            });
        });
        c.Spacer(15);
        c.Row(r => {
            r.RelativeItem(1, col => col.BarCode("FAC9901", "code128", 160, 35));
            r.RelativeItem(1, col => col.Text("Total: € 1,500.00").H2().Bold().Color("#16A34A").Right());
        });
    });

// 2. Renderizado In-Process directo en Rust en ~35 ms!
byte[] pdfBytes = doc.RenderPdf();
File.WriteAllBytes("factura_csharp.pdf", pdfBytes);
Console.WriteLine($"✅ PDF generado ({pdfBytes.Length} bytes) en microsegundos!");

Ejemplo de Implementación Java 11+ 
import dev.reportforge.ReportDocument;
import java.io.FileOutputStream;
import java.util.List;
import java.util.Map;

public class Main {
    public static void main(String[] args) throws Exception {
        ReportDocument doc = ReportDocument.create(p -> p.a4().portrait().margin(15))
            .title("Factura en Java")
            .content(c -> {
                c.text("Facturación Electrónica en Java", t -> t.h1().bold().color("#1E40AF"));
                c.text("Soporte Unicode completo: á é í ó ú ñ €", t -> t.caption());
                c.spacer(10);
                c.table(t -> {
                    t.column("Código", "sku", col -> col.width(70));
                    t.column("Descripción", "desc", col -> col.flex(3));
                    t.headerBackground("#1E40AF");
                    t.zebra(true);
                    t.data(List.of(
                        Map.of("sku", "JV-01", "desc", "Licencia Enterprise Spring Boot")
                    ));
                });
                c.spacer(10);
                c.qrCode("https://reportforge.io/verify/FAC-JAVA", 60);
                c.spacer(10);
                c.barcode("FACJAVA2026", "code128", 160, 35, true);
            });

        // Renderizado nativo in-process
        byte[] pdfBytes = doc.renderPdf();
        try (FileOutputStream out = new FileOutputStream("factura_java.pdf")) {
            out.write(pdfBytes);
        }
        System.out.println("✅ PDF generado exitosamente (" + pdfBytes.length + " bytes)!");
    }
}
